# Release notes

## 1.0.0 — Initial release

BELOW THE SIGNAL is a complete, compact recovery mission: enter the wreck, collect three black-box recordings, and escape through the docking hatch.

- Explore through darkness using sonar pulses that also attract the creature.
- Choose between quiet movement and noisy sprinting.
- Manage oxygen and recover emergency air cylinders.
- Read visual sonar and threat cues alongside synthesized audio.
- Open the recording journal with J to read recovered transmissions while the dive is paused.
- Pause, toggle fullscreen, mute sound, and select reduced motion.
- Run the desktop game from Python with pygame-ce; the environment, effects, and audio are generated procedurally, with pygame-ce's bundled interface font.

The initial scope is one single-player mission. There are no accounts, online services, or external asset downloads.

The source code and authored procedural assets are released under the MIT License. See the project README for installation, controls, and test commands.
